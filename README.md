# Code Excercises

This is a repository for doing coding excercises done by university students and enterprise interns. This project can serve as a strong dataset for understanding and preparing the minimum amount of code to do the basic tasks. Several of the major interview questions are based of these responses. 

**Note**: This is a curated list of programs that served to help in major tasks. For the reasons of NDA, most of the context cannot be showed, so it has been renamed. However, a budding student can go through this repository and learn new skills for their tech stack.

## How to read this repository

Simply go to the folder of the programming language of your choice, and explore the brilliant pearls of programming expertise shown in these repositories.
